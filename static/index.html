    收件箱使用教程

    可以做什么

    • 多邮箱在“邮箱管理”中添加多个邮箱，列表合并显示，也可用左上角下拉框只看某一个邮箱。
    • 实时推送页面打开期间服务会定时检查各邮箱，新邮件通过 WebSocket 自动出现在列表顶部，无需手动刷新。
    • 只读收件箱读取 INBOX 邮件，不发送、回复、删除或移动邮件。
    • 搜索邮件按发件人或主题快速筛选当前邮件列表。
    • 查看正文点击邮件后在右侧以富文本完整显示正文，包括图片、样式、链接和附带的图片。
    • 即时同步点击“同步收件箱”重新读取最近 50 封邮件。
    • 热更新设置点击“邮箱管理”添加、修改或删除邮箱，保存后立即生效。

    首次配置：按这 5 步操作

    1. 先在邮箱服务商后台开启 IMAP登录你的网页版邮箱，进入“设置 / 账户 / 邮件协议”一类的页面，打开 IMAP 服务。部分服务商不会直接使用网页登录密码，而是要求创建“授权码”或“应用专用密码”。
    2. 打开本页面右上角的“邮箱管理”首次打开时会自动弹出；之后可以随时点击“邮箱管理”重新打开。
    3. 填写 IMAP 服务器和端口服务器填邮箱服务商提供的 IMAP 主机名，端口通常填 993。本服务使用 IMAP SSL，不要填写 SMTP 服务器，也不要填写网页邮箱地址。
    4. 填写邮箱账号和授权码账号通常是完整邮箱地址。密码框填写授权码/应用专用密码；如果服务商明确允许邮箱密码，也可以填写邮箱密码。授权码不会显示在页面状态接口中。
    5. 点击“保存并连接”配置保存在部署服务器，保存成功后页面会立即尝试读取 INBOX。右上角显示已配置的邮箱数量并出现邮件列表，代表配置已生效。

    常用邮箱参数

    服务商IMAP 服务器端口
    QQ 邮箱imap.qq.com993
    163 邮箱imap.163.com993
    Gmailimap.gmail.com993
    Outlookoutlook.office365.com993

    以上参数仅适用于启用了 IMAP 的账号。企业邮箱、学校邮箱或自定义域名邮箱请以管理员/服务商给出的 IMAP 地址为准。

    如何开启 IMAP 并取得登录凭据

    QQ 邮箱

    1. 在浏览器登录 QQ 邮箱，进入设置 → 账号。
    2. 找到 POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务。
    3. 开启 IMAP/SMTP 服务，按页面要求完成安全验证。
    4. 复制页面生成的授权码；它只会完整显示一次，请先妥善保存。
    5. 回到本页“邮箱管理”：服务器填 imap.qq.com，端口填 993，账号填完整 QQ 邮箱地址，密码框填刚生成的授权码。

    163 邮箱

    1. 在浏览器登录 163 邮箱，打开设置 → POP3/SMTP/IMAP。
    2. 开启 IMAP/SMTP 服务，并根据页面提示完成手机验证。
    3. 创建或重置客户端授权密码，并复制新生成的授权码。
    4. 回到本页“邮箱管理”：服务器填 imap.163.com，端口填 993，账号填完整 163 邮箱地址，密码框填客户端授权码。
    5. 若提示认证失败，请重新生成授权码；不要填写网页版邮箱登录密码。

    Gmail

    1. 打开 Google 账号的安全性页面，先开启两步验证。
    2. 在安全性页面搜索并进入应用专用密码；若该入口不存在，可能是组织策略、儿童账号或高级保护功能不允许创建。
    3. 为邮件客户端创建一个应用专用密码，复制生成的 16 位密码；填写时可以不保留空格。
    4. 回到本页“邮箱管理”：服务器填 imap.gmail.com，端口填 993，账号填完整 Gmail 地址，密码框填应用专用密码。
    5. Google Workspace 账号还可能需要管理员允许 IMAP；被策略禁用时请联系组织管理员。

    Outlook / Microsoft 365

    1. 先确认账号允许使用 IMAP；组织账号可能由 Microsoft 365 管理员统一控制。
    2. 如果账号已开启多重验证且安全页面提供应用密码，创建并复制一个新的应用密码。
    3. 回到本页“邮箱管理”：服务器填 outlook.office365.com，端口填 993，账号填完整邮箱地址，密码框优先填应用密码。
    4. 点击“保存并连接”。如果组织只允许 OAuth2 或已禁用基本身份验证，本服务当前无法登录，需要管理员开放可用的 IMAP 登录方式。

    字段怎么填

    IMAP 服务器
    接收邮件的服务器主机名，例如 imap.gmail.com。不要写 https://，也不要写网页邮箱首页地址。
    端口
    SSL 加密连接使用 993。只有服务商明确要求其他端口时才修改。
    邮箱账号
    通常填写完整地址，例如 name@example.com。少数企业邮箱使用员工编号或其他登录名，请按服务商要求填写。
    授权码 / 应用密码
    这是 IMAP 登录凭据，不一定等于网页登录密码。修改服务器或账号时密码框留空，会保留已经保存的授权码。

    配置完成后怎么用

    1. 同步点击“同步收件箱”，读取最近 50 封 INBOX 邮件。同步不会标记已读。
    2. 搜索在搜索框输入发件人姓名、邮箱地址或主题关键词，列表会即时筛选。
    3. 阅读点击左侧邮件，右侧会显示发件人、收件人、主题、日期和完整的富文本正文。
    4. 修改配置点击“邮箱管理”，对某个邮箱点“编辑”更换服务器、端口或账号后保存，或点“添加邮箱”接入新邮箱；无需重启服务。

    连接失败时检查

    • 登录失败确认 IMAP 已开启，并使用授权码/应用专用密码；不要把 SMTP 密码或网页验证码填进来。
    • 无法连接服务器确认服务器拼写正确、端口为 993，且当前网络没有拦截 IMAP SSL。
    • Gmail 拒绝登录通常需要开启两步验证并创建应用专用密码；普通 Google 账号密码经常无法直接用于 IMAP。
    • 163/QQ 拒绝登录重新进入网页版邮箱生成新的 IMAP 授权码，并确认 IMAP 服务开关已打开。
    • 修改后仍显示旧邮箱重新点击“同步收件箱”；页面不会在修改设置后自动保留旧邮件列表。

    连接设置保存在部署服务器。读取邮件使用 IMAP SSL 只读模式，不会改变邮件的已读状态。
